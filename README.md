# pulse
Extract artist and track name from any music page and instantly open it in Spotify via iOS Shortcuts.

## Setup

```bash
bun install
```

```bash
bun --bunx skills add https://github.com/vercel-labs/vercel-plugin --skill vercel-functions
bun --bunx skills add https://bun.sh/docs
```

## API

Vercel function: `api/resolve.ts`
